# Lectron 設計仕様書（正本 / v4）

本書はブラウザゲーム **Lectron**（旧プロトタイプ名：OVERCHAIN SPLASH v3）のシステム・数値バランス・UI/描画仕様の正本です。AIエージェント（Antigravity / ChatGPT 等）および開発者がコード改修・機能追加を行う際の基準として参照します。

---

## 1. アーキテクチャ方針

- **配布形態**：外部CDN・外部フォント・外部画像・外部音声に一切依存しない単一HTMLファイル（`index.html`）。
- **対応環境**：PCブラウザおよびスマートフォン縦持ち（最小幅 360px、標準100dvh・通常時縦スクロール禁止、短い／狭い画面ではスクロール可・ブラウザ拡大を許可）。
- **音声（Web Audio 完全シンセ合成）**：
  - 初回操作で `AudioContext` を起動・再開し、ミュート状態と完全同期する。
  - イベント別専用シンセ音（7系統）：
    1. **励起ヒット**：残耐久に応じた音高の軽快なプラック音
    2. **電離連鎖**：ペンタトニック音階（`[261.63 .. 1046.50]`）の上昇破裂音＋高域倍音のきらめき
    3. **壁反射・偏向板**：非整数倍音による金属的なショートクリック
    4. **凍結解除**：事前生成ホワイトノイズのハイパスフィルタ＋結晶ピングによる氷砕け音
    5. **方向装甲ブロック**：硬質な低音ダンピング音（装甲破壊時は破砕スナップ）
    6. **Wave昇格・ステージクリア**：上昇アルペジオ＋軽いサブベース（失敗時は下降チャイム）
    7. **ロック締結・ショップ購入**：初弾タップ時の2段機械ラッチ音、ショップ購入・装備切替の精密クリック
  - 大連鎖時の音割れ防止として、マスター段に `DynamicsCompressorNode` と同時発音数上限（最大14ボイス）・イベント別短時間スロットルを備える。
- **Canvas軽量化ルール**：
  - モバイル60fps維持のため、描画ループ内での `ctx.shadowBlur` 使用および毎フレームの `createRadialGradient` 生成を禁止とする。
  - 起動時にオフスクリーンCanvasで64×64の電子雲スプライトを色別事前ベイク（`CLOUD_SPRITES`）し、`ctx.drawImage`＋加算合成（`lighter`）で描画する。
  - 同時飛沫（電子ビーム）上限は **80発** を安全弁として維持する。

## 2. 2つのゲームモード仕様

| 項目 | TACTICAL モード（初期モード） | OVERDRIVE モード |
|---|---|---|
| 勝利条件 | 盤面上の全原子を電離（バンパー除く） | 規定パルス数以内に目標スコア突破 |
| 盤面サイズ | 6×6 固定 | 初期 6×6（1タップ内連続全消しで最大 8×8） |
| 初期タップ / 上限 | 初期 10 / 上限 15（ステージ間引継） | Stage 1〜9は 5 / Stage 10以降は 4（毎面リセット） |
| 初期コイン / 初期ツール | 4🪙 / `スワップ` 1個 | 4🪙 / `ピンポイント爆破` 1個 |
| 初期装備枠 | 4枠（調整で2〜12枠） | 6枠（調整で2〜12枠） |
| 残弾回復・報酬 | 3連鎖ごと +1 TAP（上限超過分 +1🪙）。クリア報酬 `3 + min(4, floor(stage/3))` 🪙 | クリア報酬 `4 + min(5, floor(stage/3)) + 残タップ×2` 🪙。1タップ2回リフィルで +2🪙 |
| RNG方針 | 確率発動レリックなし（盤面・ショップ抽選はランダム） | 確率発動レリック・上振れ爆発を許容 |

### TACTICAL 段階的ギミック解禁スケジュール
初期盤面は密度 `min(0.84, 0.56 + stage * 0.02)`、臨界セルを **最低4個保証**。
- **Stage 1〜2**：基本原子（十字4方向、初期Lv.4電離）
- **Stage 3〜**：斜め原子（×方向4発射、`d_xy` 4葉電子雲）
- **Stage 5〜**：磁気偏向バンパー（`/` または `\` で90度偏向、最大4個）
- **Stage 7〜**：極低温凍結マス（1発当てて解凍、凍結中は電子雲の揺らぎが完全静止）
- **Stage 9〜**：方向装甲（`UD` 上下遮断 / `LR` 左右遮断）
- **Stage 11〜**：予告2Wave（1Wave全消し後に湧く2Wave目配置を四隅ブラケットで事前予告）
- **Stage 13〜**：Lv.5高耐久原子解禁

### OVERDRIVE エスカレーション・リフィル＆ボス制約
全消し時、飛行中の電子ビームを消さず **0.15秒後** に新盤面をポップイン（進路延長線上への配置補正あり）。ターン終了後、次タップ開始時に `6×6 / 初期Lv / Wave 1` へリセット。

| Wave | 盤面サイズ | 必要電離Lv（`inc=1`時） | Wave倍率 |
|---|---|---|---|
| Wave 1 | 6×6 | Lv.4 | ×1.0 |
| Wave 2 | 6×6 | Lv.5 | ×2.5 |
| Wave 3 | 7×7 | Lv.5 | ×5.0 |
| Wave 4 | 7×7 | Lv.6 | ×10.0 |
| Wave 5 | 8×8 | Lv.7 | ×20.0 |
| Wave 6+ | 8×8 固定 | 毎回 `+inc` | 毎回 ×2.0 |

- **スコア計算式**：`round((基礎点 + 連鎖数 * 2) * Wave倍率 * 乗算レリック)`（基礎点初期値10）
- **目標スコア式**：`area = floor((stage-1)/3)`, `sub = (stage-1)%3`, `base = 420 * (odCurve ^ area)`（`odCurve` 初期値 `4.5`）, `subMult = [1.0, 1.7, 2.6][sub]`（10の位丸め）
- **連鎖加速**：15連鎖 `1.25x` → 30連鎖 `1.5x` → 60連鎖 `2.0x`
- **ボス制約（各エリア3ステージ目）**：
  1. `freeze`（氷結の盤面）：ランダム6マス凍結開始＋盤面四隅の霜フレーム
  2. `wind`（偏西風）：左射撃不可・右方向2連射＋左壁封鎖シャッター＆右向き気流アニメ
  3. `onetap`（ワントライ）：初期タップ2回・高密度70%臨界スタート・初期Wave倍率×2.0

## 3. レリック・変異・ツール仕様

### TACTICAL専用レリック（確率発動なし・8種）
1. `first_pierce`（ファーストアロー / 4🪙）：各タップ最初の電離ビームが貫通
2. `edge_reflect_2`（エッジリフレクト / 4🪙）：各タップ最初に壁へ当たった2発が反射
3. `phase_shift`（フェーズシフト / 5🪙）：各ステージ1回、対象1マスの射出方向を十字↔斜めに切替（アクティブスキル）
4. `push_one`（プッシュ1 / 4🪙）：各ステージ1回、タップ消費なしで原子を隣接空きマスへ移動（アクティブスキル）
5. `overcharge_det`（オーバーチャージ / 5🪙）：臨界セルの直接タップで8方向発射
6. `thaw_wave`（解凍波 / 4🪙）：ステージ開始時、凍結マスを最大2個自動解凍
7. `chain_tax`（効率回収 / 6🪙）：+1 TAP 回復条件を 3連鎖 → 2連鎖 に短縮
8. `armor_breaker`（装甲ブレイク / 5🪙）：直接タップしたマスと上下左右4マスの方向装甲を破壊

### OVERDRIVE専用レリック（10種）
1. `wall_reflect`（リフレクト壁 / 4🪙）：外周で1回跳ね返る
2. `bounce_charge`（跳弾チャージ / 4🪙）：反射ビーム命中で基礎点+25
3. `cross_burst`（クロスバースト / 5🪙）：ビーム交差で周囲3×3に+1ヒット（1Wave最大4回）
4. `crit_refill`（臨界リフィル / 5🪙）：リフィル時35%で臨界出現
5. `chain_ripple`（連鎖の余波 / 4🪙）：5連鎖ごとに残耐久最大の原子へ1ヒット
6. `chain_lucky`（チェーンラッキー / 5🪙）：電離時25%で追加の4方向波を発射
7. `split_bounce`（スプリットバウンス / 6🪙）：壁反射時40%で斜め方向に2股分裂
8. `crit_pop`（クリティカルポップ / 5🪙）：電離時20%でスコア×4.0
9. `last_stand`（背水の陣 / 5🪙）：残タップ1以下ですべてのスコア×2.5
10. `snowball`（雪だるま機関 / 5🪙）：1タップ15連鎖以上で恒久基礎点+3

### ドロップ変異（OVERDRIVEショップ・3種）＆使い切りツール（最大3枠・共通3種）
- **変異**：`cross`（斜め+12% / 4🪙）、`golden`（+1🪙＆基礎点2倍 +10% / 4🪙）、`prism`（1発即電離・6方向貫通 +8% / 5🪙）
- **ツール**：`swap`（任意2マス入替 / 3🪙）、`blast`（指定1マス強制電離 / 3🪙）、`mirror`（次1タップ外周2回反射壁 / 3🪙）
- **ショップ補足**：TACTICALでは `残弾補給 (+3 TAP / 3🪙)` を販売。リロールは `2🪙` 開始で毎回 `+1🪙`。クリア時はチャイム再生＋0.65秒の余韻バナー後にショップを開く。

## 4. UI・ビジュアル・ゲームフィール設計ルール

- **数字ゼロの電子雲表現＆量子跳躍モーション**：
  - 通常設定ではセル中央に数字は描画しない（設定で残耐久表示可）。残耐久は電子雲の半径・色相・形状・点群密度で伝える（残5+：ディープインディゴ / 残4：シアン / 残3：エメラルド＋2sノードリング / 残2：オレンジ＋4方向張り出し / 残1：ホットピンク＋白熱コア＋破線臨界リング＋微振動）。
  - **量子跳躍（Quantum Jump）**：被弾・タップによる準位上昇時、電子雲が一瞬中心へ収縮＋白熱コア閃光してから次準位半径へ膨張・収束する（`reducedMotion()` 時は無効）。
  - **極短ヒットストップ**：オーバーチャージ・クリティカルポップ・プリズム電離・クロスバースト・Wave昇格・クリア決定打の節目にのみ 24〜32ms のヒットストップ（クールダウン付き）を入れ快感を際立たせる（`reducedMotion()` 時は完全無効）。
- **Dual-Chassis HUD ＆ 控えめBEST表示**：
  - TACTICALは15セル薬莢マガジン＋連鎖ダイヤピップ、OVERDRIVEは目標スコア圧力バー＋Wave倍率コア＋残パルスセルへ物理的に切り替える。
  - モード別の自己ベスト到達ステージをHUD上部のステージメタ横に高さを増やさず控えめに表示する。
- **非遮蔽ハーフシート・ロードアウト ＆ 役割タグ・変異表示**：
  - 0タップ前はアンバー枠で `UNLOCKED` 表示。タップで盤面を隠さない下部45dvhトレイを展開し、初弾タップで自動収納＆ `LOCKED` 化。戦闘中は発動したレリックのスロットが上へバウンス発光する。
  - ショップおよびロードアウトの各カードには極小役割タグ（`貫通` `反射` `連鎖` `倍率` `制御` / `変異` `ツール` `補給`）を表示する。
  - OVERDRIVE中は現在積んでいる3変異レベル（クロス/黄金/プリズム）をレリックバー見出し・ロードアウト・ショップでコンパクトに確認できる。
- **初見UX（`?` ミニヘルプ ＆ ⚙ 設定モーダル整理）**：
  - 上部バーの `?` から、1画面に収まるミニヘルプ（電子雲の色と励起段階、斜め4葉＝×方向、0タップ前ハーフシート入替、2モード比較）を表示（`Escape` キー・背景クリックで閉じる）。
  - `⚙` モーダル最上部に一般設定（残耐久数字表示・演出軽減・設定初期化）を配置し、7本バランス調整スライダーとJSON入出力は `<details>`（「詳細バランス調整」）に折りたたむ。
- **ライブチューニング JSONスキーマ**：
  ```json
  {
    "tacSlots": 4,
    "odSlots": 6,
    "odCurve": 4.5,
    "probMult": 1.0,
    "speedMult": 1.0,
    "assistRate": 65,
    "initBurstLv": 4,
    "refillLvInc": 1
  }
  ```


## 5. チューニング・保存・継続プレイ・デバッグ

| キー | 初期値 | 最小 | 最大 | 刻み |
|---|---:|---:|---:|---:|
| tacSlots | 4 | 2 | 12 | 1 |
| odSlots | 6 | 2 | 12 | 1 |
| odCurve | 4.5 | 2 | 8 | 0.5 |
| probMult | 1 | 0.5 | 2 | 0.1 |
| speedMult | 1 | 0.5 | 2.5 | 0.1 |
| assistRate | 65 | 0 | 100 | 5 |
| initBurstLv | 4 | 3 | 5 | 1 |
| refillLvInc | 1 | 0 | 2 | 1 |

- JSONはオブジェクトのみ受理。既知キーの有限数値または数値文字列を範囲・刻みに補正し、未知・無効値は無視する。構文エラーと値エラーを区別する。欠落値は既存設定を保持する。
- `localStorage`（パス単位、全読み書き例外保護付き・不可環境でもゲーム継続）：
  - `lectron.preferences.v1:<pathname>`：チューニング・ミュート・数字表示・演出軽減を保存。初期化ボタンあり。
  - `lectron.records.v1:<pathname>`：TACTICAL・OVERDRIVE それぞれの「最高到達ステージ」「最高累計スコア」「最大連鎖」を保存。リザルト画面では更新項目に `NEW BEST` バッジを表示し、「📋 戦績をコピー」ボタンでモード・到達・スコア・最大連鎖・装備レリック数をクリップボードへコピー可能（トースト通知付き）。
  - `lectron.run.v1:<pathname>`：ステージ開始時・ショップ遷移時（およびショップ購入・開幕ロードアウト変更時）にラン状態・盤面・インベントリを厳密検証付きで自動保存し、再読み込み時に途中再開する。`↻` リスタート・ゲームオーバー・モード切替で破棄し、破損データ検出時は安全に削除して新規開始する。`?debug=1` 状態は保存しない。
- 全レリック解放、コイン+50、ステージスキップ、盤面再生成は URL の `?debug=1` でのみ表示・実行可能。これは誤操作防止であり、不正防止のセキュリティ境界ではない。
- TACTICALはランダム盤面のため、解けない盤面も意図的に許容する。ソルバー・解可能性保証・解けるまでの再生成は導入しない。

## 6. ツール・ボスの追加仕様

- スワップ：原子のある2セルを選択して交換。空き・偏向板は選択不可。キャンセルでは消費しない。
- 爆破：原子を直接電離し、通常の連鎖処理に入る。通常残弾を消費せずツールを1個消費する。
- ミラー：使用時に消費し、次の連鎖終了まで反射効果を有効化する。
- OVERDRIVEボス：3の倍数のステージで氷結→偏西風→ワントライの順に巡回。氷結は非リフィル時に最大6原子（80試行上限）。ワントライは2タップ、初期Wave倍率2.0、初期密度78%、配置原子の70%を臨界にする抽選（残りは通常抽選）。偏西風は左向き射出を抑え右向き2連射。

## 7. アクセシビリティ・開発時検証

- キーボード：盤面へのフォーカス、矢印、Enter/Space、Escape。選択セルの行列・残耐久・種別を読み上げ用テキストに反映。数字表示と演出軽減は任意。端末の reduced-motion 指定も尊重する。通常時の電子雲デザインを維持する。
- ショップ抽選は Fisher-Yates 法。外部由来文字列（将来のランキング名など）は innerHTML に補間せず textContent 等を使う。現行の内部定数によるテンプレートは維持する。
- Node.js 22：`node tests/smoke.cjs`。本体のスクリプトを解析して、入力検証、目標式、Wave、ビーム上限、ショップの抽選・価格、設定スキーマとデバッグの境界を検査。加えて `node tests/boot.cjs` で簡易DOMモック上の起動・入力・設定復元・Wave遷移・ビーム上限・ショップを実行検証する。ブラウザ実機確認とは別に扱う。タッチは指を離した時に確定し、複数指・移動・pointercancel では取り消す。
