# Lectron

**Lectron** は、量子力学の「電子雲（Electron Cloud）」の励起・電離連鎖をテーマにした、ローグライク連鎖パズル・ブラウザゲームです。  
外部CDN・外部フォント不使用の完全自己完結型単一HTMLファイルで動作し、PCおよびスマートフォン縦持ち（360px〜）の両方に対応しています。

## 特徴

- **数字ゼロの電子雲ビジュアル（60fpsモバイル最適化）**
  - `shadowBlur` を一切使わず、事前ベイクした64×64の電子雲スプライトと確率点群の明滅で描画。
  - 励起準位はサイズ・色相・4葉の張り出しで直感的に判別可能：  
    基底シアン → 2sノード（エメラルド） → 高励起4方向張り出し（オレンジ） → 臨界白熱＆破線リング（ホットピンク）。
  - 斜め射出セルは `d_xy` 軌道風の斜め4葉電子雲、凍結セルは絶対零度で確率揺らぎが静止。
  - **量子跳躍（Quantum Jump）＆極短ヒットストップ**：準位上昇時に電子雲が一瞬収縮してから次準位へ膨張。オーバーチャージ・クリティカルポップ・Wave昇格などの節目には極短ヒットストップで手触りを強調（演出軽減ON時は無効）。
- **Web Audio 完全シンセ合成サウンド（外部音声ゼロ）**
  - 励起プラック・ペンタトニック上昇＋倍音電離・壁反射／偏向金属クリック・氷砕けハイパスノイズ・方向装甲低音ダンピング・Wave昇格／クリア上昇アルペジオ＋サブベース・ロック締結／購入機械クリックをリアルタイム合成。
  - マスター段の `DynamicsCompressorNode` と発音スロットルにより大連鎖時も音割れを防止。
- **2つの対照的なゲームモード（Dual-Chassis UI）**
  - **TACTICAL**：6×6固定・確率発動レリックなし（盤面・ショップはランダム）。残弾（ENERGY PULSES）を次ステージへ引き継ぎつつ、段階的に解禁されるギミック（斜め軌道・偏向板・凍結・方向装甲・予告2Wave・Lv.5）を攻略。
  - **OVERDRIVE**：全消し後0.15秒で即座にリフィル＆盤面拡大（6×6 → 7×7 → 8×8）・電離Lv上昇・Wave倍率青天井（×1.0 → ×2.5 → ×5.0 → ×10.0 → ×20.0 → 以降×2.0）。エリア3ステージ目のボス制約（氷結の盤面・偏西風・ワントライ）と3変異レベル常時確認を搭載。
- **非不可逆ロードアウト（盤面非遮蔽ハーフシート）＆役割タグ**
  - 獲得したレリックは控えライブラリにすべて蓄積。各ステージの最初の1タップ前であれば、盤面を見せたまま下部トレイで自由に装備を入れ替え可能。ショップ・ロードアウトには役割タグ（`貫通` `反射` `連鎖` `倍率` `制御`）を表示。
- **継続プレイ・リプレイ性（オートセーブ・自己ベスト・戦績コピー）**
  - ステージ開始時・ショップ遷移時にラン状態を自動保存し、スマホの再読み込みでも途中再開可能（`↻` リスタートで破棄）。
  - モード別の自己ベスト（最高ステージ・累計スコア・最大連鎖）を保存し、リザルト画面での `NEW BEST` 表示とSNS向け戦績テキストのワンタップコピーに対応。
- **初見UX（`?` ミニガイド）＆ ⚙ 設定・ライブチューニング**
  - 上部バーの `?` から1画面完結のミニヘルプを確認可能。
  - `⚙` モーダル上部に一般設定（残耐久数字表示・演出軽減・設定初期化）を集約し、詳細バランス調整スライダー（7項目）と検証付きJSON入出力は折りたたみ収納（透過Peekモード対応、デバッグ機能は `?debug=1` のみ有効）。

## 遊び方・公開（GitHub Pages）

1. ローカルで確認する場合は `index.html` をブラウザで直接開きます。
2. GitHub Pages で公開する場合：
   - リポジトリの **Settings → Pages** を開く
   - **Source** を `Deploy from a branch`、Branch を `main` / `/ (root)` に設定して保存
   - 公開URL（`https://josh-temple.github.io/Lectron/`）からスマホ・PCでそのままプレイできます

## リポジトリ構成

```text
Lectron/
├── index.html      # ゲーム本体（完全自己完結・単一HTML/CSS/JS）
├── README.md       # プロジェクト概要・公開手順
├── docs/
│   └── SPEC.md     # システム・レリック・UI描画の正本仕様書
└── tests/
    ├── smoke.cjs   # 静的制約・数値式・設定検証のスモークテスト
    └── boot.cjs    # モックDOM上の起動・操作・保存復帰・v4機能テスト
```

## 開発ガイドライン

- 変更は `main` へ直接コミットせず、フィーチャーブランチ＋Pull Requestで管理します。
- 詳細なゲームシステム・数値設計・描画ルールは [`docs/SPEC.md`](./docs/SPEC.md) を参照してください。

## 操作・設定・検証

- PC：盤面にTabで移動し、矢印キーで選択、Enter/Spaceで実行、Escapeでツール解除またはモーダル終了。`?` でミニガイド、`⚙` から残耐久の数字表示・演出軽減を選べます。
- 設定・モード別自己ベスト・進行中ランのオートセーブ（ステージ開始／ショップ時点）を `localStorage` に保存します（`↻` リスタートでオートセーブ破棄、ストレージ不可環境や破損データ検出時も安全に動作）。
- TACTICALには解けないランダム盤面も含まれます。解可能性の保証・再生成による選別は行いません。
- 開発用の最小検証：Node.js 22で `node tests/smoke.cjs` と `node tests/boot.cjs`。外部ライブラリ不要。後者は簡易DOMモックを利用するため、実ブラウザの描画・読み上げは保証しません。実機では両モード、タップ・キーボード、オートセーブ復帰、通常URLと `?debug=1`、PC幅とスマホ縦幅（360×740）の表示を確認してください。
